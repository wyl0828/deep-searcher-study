# 使用示例

DeepSearcher 提供了多个示例脚本，帮助你快速上手。每个示例对应一种常见用法。

## 📋 示例目录

| 示例 | 说明 | 主要内容 |
|------|------|----------|
| [基础示例](basic_example.md) | 展示核心功能 | 加载 PDF、执行查询 |
| [Docling 集成](docling.md) | 使用 Docling 加载文件和抓取网页 | 本地文件与网页等多种来源 |
| [Unstructured 集成](unstructured.md) | 使用 Unstructured 解析文档 | API 与本地处理 |
| [FireCrawl 集成](firecrawl.md) | 使用 FireCrawl 抓取网页 | 提取网站数据 |
| [Oracle 示例](oracle.md) | 包含路径配置的进阶示例 | 路径配置、Token 统计 |

点击任意示例即可查看完整代码和说明。
