## 目标

实现工作区级共享与检索前实时授权，让“未授权知识在检索前不可见”成立：

1. Workspace + 成员三角色（owner/editor/viewer），知识库归属工作区；
2. 每次触发知识库读取的请求都实时重新授权（会话创建授权不作凭据）；
3. 自动个人工作区迁移，legacy 数据有确定归属。

## 决策摘要（契约）

- `workspace_id NOT NULL`；名称唯一性迁移到 `(workspace_id, name)`；会话不挂工作区、经 KB 继承权限域。
- 权限用集合表达：`viewer={read}`、`editor={read,write}`、`owner={read,write,admin}`。
- 三层 access：`user_workspace_role` / `require_workspace_access` / `require_accessible_knowledge_base`。
- 实时授权链：authenticate → conversation owner（会话入口）→ require read → collection_name → Cache → Retriever。
- 403/404：不存在/非成员 404，成员角色不足 403；单 owner DB 防线 + 服务层约束。
- 授权以请求开始时的成员状态为快照，运行中流不中途鉴权。
- Cache 隔离契约：不新增跨请求答案缓存；未来若引入必须按 collection 隔离。
