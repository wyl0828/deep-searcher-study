# DeepSearcher O-05A 本地上传与任务生命周期验证

日期：2026-08-01  
范围：O-05A 本地小文件上传、持久任务、独立 Worker、失败恢复与删除清理

## 1. 结论

O-05A 已完成。产品工作台和旧学习控制台均使用 multipart 流式上传；服务端以固定
1 MiB 分块读取并在写入过程中执行大小限制和 SHA-256，PDF 结构与页数由限时独立进程
检查。文件落入受控随机路径，入库任务由独立 Worker 通过租约、退避重试和死信状态执行，
不再依赖 Web 请求结束后的内存后台任务。

本结论只覆盖默认上限 20 MiB 的本地 PDF。对象存储直传、多段上传、病毒扫描和跨实例严格
配额计费属于 O-05B，尚未实现，也不是本次验收范围。

## 2. 交付契约

- 上传阶段限制 PDF 类型、单文件字节数、页数、知识库文档数、知识库容量和实例总容量。
- 暂存文件使用随机 `.part` 名称；异常、取消和超限均清理；最终文件使用 48 位随机十六进制
  名称并原子移动到知识库目录。
- PDF 探测运行在独立子进程中并有硬超时；损坏、加密、空页和超页数文件返回稳定安全错误码。
- IngestJob 持久化可执行时间、租约、重试次数、最大重试数和错误信息；过期租约可恢复，
  可安全重试的网络故障使用指数退避，达到上限进入 `dead_letter`。
- 读取或写入超时因服务端是否已完成不可判定，不并发自动重试；手动重试前按文档 SHA-256
  删除旧分块，再串行重新入库，避免重复引用。
- 独立 Worker 纳入 `start.ps1`、`stop.ps1` 和 `status.ps1`，工作台健康检查单独报告 Worker。
- 文档和知识库删除会清理数据库、文件与向量；启动时清理过期 `.part` 和超保护期孤儿 PDF。

## 6. 剩余边界

当前实现面向单机、本地小文件工作台。只有产品明确需要超过 20 MiB 的文件、多个工作台实例
并发上传或恶意文件扫描时，才进入 O-05B：对象存储预签名直传、多段上传、内容扫描、跨实例
原子配额与存储计费。现有本地路径不会被宣传为大文件上传方案。
