# DeepSearcher 新会话学习交接

> 用途：新开 Codex 会话时恢复学习上下文。新会话应先阅读本文件，再继续学习，不需要回看旧聊天记录。

## 1. 学习者情况与目标

- 默认使用中文。
- 学习者有 Python 基础，目标是 AI 全栈应用工程师岗位。
- 目标不是背源码，而是能运行、能解释、能排障、能说明取舍，并应对面试官连续追问。
- 不包装不存在的生产能力；计划中的优化必须明确说成“尚未实现”。
- 类名、函数名和配置键可以保留英文，但第一次出现时必须先用中文解释它解决什么问题。

## 2. 必须遵守的学习方式

### 第一遍：直接详细讲解

当前处于第一遍学习。讲解者应直接给出完整内容，不要每讲一个知识点就反问学习者。

每个主题应包含：

1. 先记住的一条中文链路。
2. 它解决什么问题。
3. 为什么这样设计。
4. 一个具体例子。
5. 当前项目实际怎么实现。
6. 方案的代价与替代方案。
7. 常见错误说法。
8. 面试标准表达。
9. 当前项目的诚实边界。

第一遍允许在一个完整章节讲完后给出“下一节是什么”，但不要要求学习者现场回答。

### 第二遍：模拟面试

“第二阶段学习”仍属于第一遍详细讲解，不等于“第二遍模拟面试”。只有全部计划阶段的知识讲完后，才进入第二遍：

- 学习者先用自己的话回答。
- 讲解者纠正术语、因果和事实边界。
- 面试官连续追问。
- 不要求逐字背标准答案。

## 7. 当前不能说错的关键事实

1. DeepSearcher 是项目；DeepSearch 是查询策略。
2. 默认查询先由 RAGRouter 选择 DeepSearch 或 ChainOfRAG，不是默认走 NaiveRAG。
3. Chunk 是向量化和检索单元。
4. overlap 缓解切分边界；`wider_text` 补充生成上下文。
5. `1500/100` 是默认切分参数，没有评测证明最优。
6. 相同维度不代表不同 Embedding 模型兼容。
7. 当前默认 L2 是距离，越小越近。
8. Milvus 的 `score` 字段当前实际承载 distance。
9. 空结果也可能是系统失败。
10. LLM 路由输出必须校验。
11. DeepSearch 的 Rerank 更接近逐条 YES/NO 过滤。
12. DeepSearch 在 `max_iter=1` 时不会执行反思。
13. ChainOfRAG 默认关闭 early stopping，因此默认没有充分性反思。
14. Trace 是应用执行事件，不是模型内部思维链。
15. 当前 ChainOfRAG 不是 CoRAG 论文的完整复现。
